Quickstart

Use the Stream API base URL from your application. API credentials for upstream services stay server-side.

const STREAM_API = 'https://stream.leetec.online'; const response = await fetch( `${STREAM_API}/api/youtube-search?q=Citizen%20TV` ); const channels = await response.json();
Use API keys only from the developer dashboard when your project account is enabled. Never expose private upstream credentials such as TMDB, YouTube, Jamendo, or YOCINEMA keys in browser code.
